# Carbon–Service Frontier for Public EV Charging

Reproducibility materials for *Carbon and Charging Service Tradeoffs of Stationary Storage at Public EV Charging Sites* by Qiang Ai, Zhijie Wang, and Kexiang Huang.

The study uses public AC charging records from 12 sites in Edinburgh and Glasgow. Under a common operating budget, the analysis estimates the additional carbon savings from stationary storage at fixed early charging service, and the change in early energy shortfall at a fixed carbon target.

The repository includes Python scripts, input manifests, archived numerical results, and figure sources. Start with the [reproduction guide](traffic_carbon_microgrid_pilot/storage_value_study/submission_jte/REPRODUCE.txt) for Python setup, source-data retrieval, and commands for the main experiments and sensitivity analyses. Run the guide's commands from the [storage_value_study directory](traffic_carbon_microgrid_pilot/storage_value_study).

The [data provenance notes](traffic_carbon_microgrid_pilot/storage_value_study/submission_jte/DATA_PROVENANCE.txt) identify the original sources and terms. The reproduction scripts retrieve transaction records locally. [SHA-256 checksums](SHA256SUMS.txt) cover the archived research files.
