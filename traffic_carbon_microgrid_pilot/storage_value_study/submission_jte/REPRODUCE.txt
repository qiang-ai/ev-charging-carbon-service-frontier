Reproducing the public charging study

This repository includes separate print figures, frozen energy signals, source
manifests, code, and numerical outputs. Session-level
source tables and prepared session indexes are recovered by the instructions below.
Run commands with Python 3.12 from storage_value_study unless otherwise indicated.

1. Install the dependencies in an isolated Python environment.

   python -m pip install -r ../requirements.txt

2. Recreate the input sessions from the public archives. The download step verifies
   the archived bytes and fills the omitted GridCharge transaction snapshots.

   python submission_jte/fetch_snapshots.py
   python prepare_study_data.py --offline
   python cross_year_2024/prepare_holdout_data.py --offline
   python cross_year_2024/prepare_holdout_data.py --harmonize-2023 --offline
   python submission_jte/rebuild_case_inputs.py

3. Audit the archived output and regenerate the numerical summaries and figures.

   python submission_jte/audit_service.py
   python submission_jte/audit_service.py --frontier-only --report submission_jte/results/audit_frontier_summary.json
   python submission_jte/audit_service.py --near-endpoint --report submission_jte/results/endpoint_sensitivity_audit.json
   python submission_jte/analyze_service.py
   python submission_jte/draw_research_design.py
   python submission_jte/draw_method_figures.py
   python submission_jte/draw_rolling_figure.py
   python submission_jte/plot_service.py
   python submission_jte/audit_controllers.py
   python submission_jte/audit_controllers.py --diagnostic
   python submission_jte/analyze_controllers.py

   To verify the cohort against the eight original operator workbooks and reports
   rather than the republished data, run this independent, networked cross-check.

   python -m pip install openpyxl tzdata
   python submission_jte/audit_operator.py

4. To rerun the main service and exploratory frontier solves from the reconstructed
   inputs, first keep a copy of submission_jte/results if the archived bytes are needed.

   python submission_jte/run_service.py --self-test
   python submission_jte/run_service.py --workers 3
   python submission_jte/run_frontier_service.py --workers 3
   python submission_jte/run_frontier_service.py --workers 3 --near-endpoint
   python submission_jte/run_controllers.py --workers 3
   python submission_jte/run_controllers.py --workers 3 --perfect-signals

   Then repeat step 3. Solver runtime, output hashes and some tied charging schedules
   may differ after a rerun. Reported energy shortfalls, feasibility and carbon
   objectives can be checked against the archived summaries. For slower computers,
   omit --workers. The primary and frontier runs cover 11,247 and 13,203
   scenario rows. The post hoc near-endpoint run adds 978 rows.
   The controller runs cover 420 forecast-based and 140 hindsight policy replays.
   The hindsight sensitivity supplies realized signals but withholds future arrivals.

The original full-window experiment uses the frozen protocol under cross_year_2024.
To regenerate its results without overwriting the archived anchors used by step 4,
run these commands from storage_value_study:

   python cross_year_2024/run_holdout.py --workers 3 --harmonized-2023 --results-dir cross_year_2024/replay_2023
   python cross_year_2024/run_holdout.py --workers 3 --results-dir cross_year_2024/replay_2024

Major-revision checks

From storage_value_study, after reconstructing the source inputs:

   python submission_jte/analyze_block_uncertainty.py
   python submission_jte/run_proxy_window_sensitivity.py --workers 3
   python submission_jte/audit_proxy_window_sensitivity.py
   python submission_jte/run_m2_regional.py --workers 3
   python submission_jte/run_wear_sensitivity.py --workers 3
   python submission_jte/run_online_forecast.py --workers 3

The regional command reads the supplied, checksummed historical NESO snapshots.
Use --fetch to recover missing snapshots. The window audit uses the locally
regenerated session_windows.csv. That file contains original session fields and
is omitted from the archive. It can be regenerated by the command immediately
above the audit. Other scenario outputs and the independent audit summary are
included. The online replay uses observed archival values with an assumed
two-hour release delay and audits input availability and dispatch constraints.

Figure files

Figures in submission_jte/figures are available as PDF and TIFF files,
editable SVG sources, and PNG previews. Use Times New Roman for SVG text.
figures/ALT_TEXT.txt provides figure descriptions.
DATA_PROVENANCE.txt describes the original sources, methods and terms.
literature_evidence.json records the 30 cited research articles, DOI metadata,
and evidence from each abstract and introduction.
